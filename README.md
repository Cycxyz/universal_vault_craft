# Universal Vault Craft

A modular collection of Solidity helper contracts for safely interacting with ERC-4626 vaults and LTV-style leveraged vaults across multiple assets, strategies, and execution paths.

Universal Vault Craft generalizes the ideas behind **Vault Craft** into a reusable, asset-agnostic toolkit designed to support:
- Multiple collateral and borrow tokens
- Multiple collateral dexes
- Multiple flashloan sources
